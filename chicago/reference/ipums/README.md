# IPUMS source data

The files that were in this directory (`H_*.csv`, `nhgis0001_*`) are
extracts from IPUMS USA and IPUMS NHGIS, both licensed under the IPUMS
Conditions of Use, which prohibits redistribution without permission
and carries a liability clause for violations.

Despite that restriction, these extracts have been published to
Internet Archive as part of this project's research corpus, with the
required citation and an explicit redistribution-restriction notice
included in each item (see `ipums-usa.yaml` and `ipums-nhgis.yaml` in
this directory, and `NOTICE.txt` within each Internet Archive item).
This was a deliberate, informed decision by the project owner, not an
oversight — see git history on this file/directory for context.

If you are reusing this data yourself, do not treat its presence here
as a redistribution license. Request your own extract:

- https://usa.ipums.org/
- https://www.nhgis.org/

Local, non-redistributed copies (including the underlying zips and
shapefile components) live at
`projects/archive/data/chicago/reference/ipums/` (sibling to this repo,
not tracked in git).
