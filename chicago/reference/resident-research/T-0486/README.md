## Method and limits

Exact names were searched first across the repository corpus, directories, institutional sources and strong local histories; justified spelling/OCR variants were used only where warranted. Same-name hits remain candidates unless date, place, occupation, kinship, paired-name continuity or another independent discriminator bridges the source to the postal person. Negative searches are documented negatives, not proof of nonexistence. No canonical household/person facts are silently promoted by this pass.
