# Era plates on the Temporal Observatory (T-2036)

Greyscale web derivatives (≤720 px, JPEG) shown inside the destination tiles on `/4d/`.
Each is cropped from an image already committed to this repository with its rights recorded
there; none is new evidence and none is shown as a claim about the scene.

The design package proposed Herriott's *The Point, 1833* for the 1835 tile and a user-supplied
street photograph for 1904. The Dearborn drawbridge replaces Herriott because the tile's own copy
names the drawbridge and because Herriott's drawing depicts Potawatomi lodges, which the AGENTS.md
standing constraint keeps off decorative surfaces; the 1904 photograph has no rights record in the
repository, so the HABS view of Glessner House stands in until one is recorded.
