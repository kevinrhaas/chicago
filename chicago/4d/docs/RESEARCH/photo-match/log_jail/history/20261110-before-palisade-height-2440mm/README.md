# Previous retained jail comparisons

Exact canonical pairs and match records saved before the 2026-11-10 refresh for the reconstructed palisade height trial (3.05 m to 2.44 m). `bindings.json` records their hashes and the immutable camera, source and model inputs checked before rendering. These historical records retain their original paths and describe the prior inputs; they are not current image acceptance.

The earlier records bind an earlier enclosure renderer, so these are historical comparisons rather than a controlled one-variable pixel experiment. The current canonical pairs render the current native enclosure renderer with the same authored cameras, full sources, core and keeper masters and placements. The current review still differs from both sources.
