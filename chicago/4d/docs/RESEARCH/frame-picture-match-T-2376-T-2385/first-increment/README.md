# Green Tree, Sauganash and first Tremont — first picture-led rebuild

Reviewed 2026-10-23. These actual pinned Blender 4.5.3 previews use the canonical
`structure_id__phase_id` emitter identity. Each panel preserves the same source,
camera, intrinsics, light and renderer helpers for the committed-before and
proposed-after views. Before models are from commit 575b4968569283177e36e92878b2a84c5554068e.
All verdicts remain **differs**. No original image-match ticket is closed.

T-2376 adds seven upper bays on the pictured south wall and wall-coloured main
gable clapboard. T-2383 adds the pictured main-end upper/attic sash and continues
white clapboard around them. T-2385 replaces the former text-only two-storey
reconstruction with Gifford's three-storey shuttered corner form, raised entries,
arched gable proxy, four offset stacks and a roof spar. Concealed faces, metric
details and colours remain reconstruction. Placement, footprints and phase dates
are retained; no image pixels become geographic control.

The per-building observations list unresolved differences. Green Tree and
Sauganash cameras have off-image principal points and remain provisional drawing
fits; the Sauganash main-master preview omits the separately built log annex.
Tremont's envelope fit is also provisional. Roofs, openings, grouped wings,
materials, context, chronology and other ticket pictures still need refinement.
Tremont has no flag cloth yet; its arch's lettering/glazing interpretation remains
open. These research cameras/matches are copied audit receipts, with original
temporary paths, outside `data/reference_views`; they are not accepted gate views.
