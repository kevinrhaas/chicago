# Photographic sky used for model review

[Overcast Soil (Pure Sky)](https://polyhaven.com/a/overcast_soil_puresky),

This is an optional lighting environment for actual-GLB Cycles review renders.
It supplies photographed cloud radiance and glass reflections; it is not a
Chicago historical record. It contains no architecture and is never projected
onto the building. The clear and mathematical-overcast review modes remain
available for fixed, repeatable comparison. Each render records its lighting
mode, environment hash, orientation and exposure. The web model's ordinary
renderer remains a separate validation target.
