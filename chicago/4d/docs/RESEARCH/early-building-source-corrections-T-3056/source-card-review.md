## Reachability and honest use

`compile_scene.build_sidecar` collects typed sources from the selected phase and listed historical fields. It does not parse source IDs from free-text research_note. The schema has no existing general top-level context_sources field. Therefore the new Calisphere catalogue has no typed building/form edge: its emitted source-use record honestly has edges=[], uses=[], while its bibliographic citation is available in the source index. The jail card's research_note separately carries item ID, copy date and complete required institutional credit. Do not add the catalogue to a geometry attribute to manufacture a backlink. A generic record_only form assertion is technically possible but is not an established contextual-source mechanism and adds a confidence input to the mesh recipe.

`SOURCE_FIELD_SURFACE` explicitly keeps access_notes internal, including the new Calisphere /tmp capture path. A pure call of cite(ids,sources) then compile_source_use.public_text(citations) for all five new source records preserved every citation unchanged; no /tmp or /workspace path is emitted in those public citation fields. No new filtering framework is needed.
