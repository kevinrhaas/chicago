# 1729 Prairie, the George M. Pullman house, 1922 — the Tribune's demolition photograph, reference copy for the image gate (T-1881)

"PULLMAN HOME BEING WRECKED.", a halftone in the *Chicago Tribune* of 6 July 1922: one face of the
house nearly square on, the mansard already pulled down, the walls standing to the cornice and the
rubble heaped before them. Which face is not settled: the owner read it first as the Prairie front,
then as the 18th Street side, and its windows match neither as the earlier photographs show them
(the source record's note). Chicagology reproduces it on its
1729 S. Prairie page; the Prairie library lists it as `a16-cgy-tribune-1922-pullman-wrecked`. The
owner uploaded this cleaner copy on 2026-11-07, and it is committed unaltered.

**Rights: public domain** (a US newspaper photograph of 1922). Forms, planes, places and proportions
are read from it; nothing is derived from the image as an asset.
