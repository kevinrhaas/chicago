# 1729 Prairie, the George M. Pullman house — J. W. Taylor's photograph no. 1445, reference copies (T-3161)

Two prints of one negative by J. W. Taylor (Chicago), 1890s, in the Art Institute of Chicago's Ryerson
and Burnham Archives, brought in from the Prairie library's image store
(`chicago/prairie_1904_v1/research/images/STORE.json`) so that 1729 Prairie is built against them (the
image gate, `data/reference_views/README.md`). Source record `aic_taylor_1445_pullman_from_sw`.

**Rights: public domain** — the owner's ruling of 2026-10-27 on T-3161: the 1890s Taylor commercial
prints are treated as public domain by age, as Taylor's 1801 Kimball print is
(`data/sources/assets/kimball_1801_photo_t2538/`), and committed with attribution. The Archives ask to be
contacted for publication. Forms, counts, places and proportions are read from them; nothing is derived
from either image as an asset, and both copies are unaltered.
