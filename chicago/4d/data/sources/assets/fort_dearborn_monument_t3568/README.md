# The Fort Dearborn Massacre monument (1893) — two photographs (T-3568)

Two pictures of Carl Rohl-Smith's bronze group on its granite pedestal on 18th Street, brought in
from the Prairie library's image store (`chicago/prairie_1904_v1/research/images/STORE.json`) so
that `fort_dearborn_massacre_monument_1893` is built against them (the image gate,
`data/reference_views/README.md`). Forms, places, depths and proportions are read from them;
nothing is derived from either image as an asset, and both copies are unaltered.
