# The jail plate: verified 1902 publication

Credit: W. E. S. Trowbridge, in Edwin O. Gale, *Reminiscences of Early Chicago and
Vicinity*, Fleming H. Revell Company, 1902. These are unmodified Internet Archive
scans of the plate facing printed p. 53 and the actual title/copyright pages.
The source record is `trowbridge_first_jail_gale_1902`; exact URLs and SHA256
values accompany the files. The plate remains in the book scan’s original
orientation. No pixels, caption, signature or border have been edited.

The actual title credits Trowbridge and prints MCMII; the actual copyright page
states 1902 and October. The US-published 1902 artwork is public domain by age.
This is independent of the UCR copy’s combined 1930 creation/issuance date and
item-specific rights statement. It clears neither added 1947 newspaper text/
layout nor any later copy-specific additions. Use the 1902 artwork for models.

The plate caption says 1836. Gale’s adjacent town-walk narrative is framed in
1835 and names the jail, palisade and John Beach’s partly enclosed house, but
supplies no metric dimensions or precise component construction sequence.
The core’s lower walls are concealed; this source does not establish a whole
July 1835 cell appearance or reconcile the contrasting Andreas depiction.
