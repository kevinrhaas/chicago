Buildings are named for their people, not their spec codes.

**The owner, 2026-08-18, verbatim: "this name is not great Reconstructed D3 one-room
frame cottage #03, i would like when you put people in the houses to give it the name of
their house or call it a vacant one room frame cottage or use a term like for let or
current for the era that it is available. you should have the marker that it is
reconstructed so that should be sufficient. give the locations useful names not
technical D3 #03 names, you can have that somewhere on the card for reference identity
purposes but dont make it the title."**

The rule for anonymous reconstructed buildings' display titles:

- **Occupied** (the residents data already joins households to buildings): title it by
  its people — "The Tuttle house" — the way a town actually named its houses.
- **Vacant**: a plain description in period voice — "A vacant one-room frame cottage" —
  or the era's own commercial phrasing where the building would have been offered:
  "To let", the 1830s term (not "for rent").
- The **RECONSTRUCTED marker already on the card is the sufficient flag** — the title
  does not need to carry "Reconstructed".
- The technical identity (D3 #03, the record id) stays ON the card as a small reference
  line, never as the title.

Named/attested buildings are untouched — this is the anonymous D-family display layer.
Search should find both the household name and the spec code. Keep the changelog entry
user-facing.

**Acceptance:** no inspector card titles itself by a spec code — the D3 #03 card from
the owner's screenshot titles as its household's house (or its period vacancy phrase),
with the code demoted to a reference line and still searchable. Gates green.
