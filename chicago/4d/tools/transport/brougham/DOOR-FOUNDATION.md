## Actual source changes

`door_aperture.py` accepts only the exact near/mid raw hashes in the existing
contracts and requires a fresh output directory. It leaves the existing producer
and contracts intact. It splits the actual right curved-shell triangles at an
opening above the actual floor. The inside skin fragments become moving backing;
the fixed wall is genuinely removed. Narrow declared relief separates this
backing from fixed cut edges. Reveals join the actual cut inner/outer skin edges.
The original lower door, glass, window frame/division, lining and front latch move
with a single rear-hung node. Their closed world positions and original finishes
are retained; all unrelated original PN streams are preserved and accounted for.
Actual frame-node identity is retained even where the parent deliberately repeats
names: four hubcap frames and their meshes share names. The canonical
`check_mid.bind_parts` source-order/range-exhaustion binding supplies the actual
node paths; a mesh/frame name alone must never select a wheel occurrence.
New hinge geometry is a declared engineering reconstruction. Its axis, dimensions
and motion are proposals until measured, not historical hardware attestation.

`check_door_aperture.py` decodes the output independently. It checks every protected
original stream against the input, checks the actual opening's core for retained
fixed surfaces, then compares every actual moving triangle with every fixed
surface, including hinge hardware. Fifteen recomputed poses retain all contacts;
no contact whitelist exists. For continuous surface separation it recursively
bounds rigid vertex displacement over each angular interval and requires a
separating-axis gap larger than that bound. Exhausted/unresolved intervals fail.
This is still a surface proof, not a solid-containment, occupant or strength proof.

The separate structure-only phase reuses that exact structural prefix, checks
closed WORLD positions (2e-7m Float32 tolerance) and byte-exact normals of every
retained original leaf part, and requires their actual door-root ancestry.
Protected originals require exact local PN and WORLD geometry at each real node
path. The intentional shell cut, moving backing and running relief are accounted
separately by actual surface area, not labelled unchanged. Structure-only success
does not set any sweep, appearance, fit or installation qualification flag.

The first temporary export and structural failure are retained outside the app.
That trial incorrectly collapsed repeated hubcap names; its failed baseline and
controls must never qualify the corrected occurrence-bound derivative.

The renderer retains each near/mid leaf outside static batching, alongside the
existing articulated pole. One door fraction updates both actual roots. A full
horizontal swept-radius exclusion, including 0.35m body margin, stops a swing
when a visitor or person enters it. The existing carriage card and picking,
terrain contacts, team, lights and material grouping remain the owning system.
Hiding/Light resets only a hidden layer; it is not a visible obstruction bypass.

The action is added to the existing Charles Nelson person thing through
`house-errands.js` and the shared `interact.js`, not a second coachman or input
system. The actual person takes a native routed `days.host(...safeTravel:true)`
path. Only actual arrival permits the swing. A timeout is a refusal, not arrival.
The engine's completion releases the owned host through `unhost`; the current
date/hour chooses the next routine and its safe route. It does not return him to
a stale fixed post through his break, invent dialogue or put him in a seat.

The installed static sidecar has no `door_operation`, so the new mechanism is
currently dormant. Runtime opt-in requires both exact new delivery hashes plus
current aperture/closed-appearance/sampled/continuous/near-mid qualification.
The recipe deliberately has all qualification flags false. No consumer may
promote them based only on this source, old C02 evidence or schema validation.
